# City Limits — Milestone 14: Phone 2.0 + Heist Room

Implemented foundation:
- Phone apps: Internet, Mechanic, Contacts, Heists plus existing apps.
- Bank operations: deposit, withdraw and loans.
- Internet listings for vehicles, aircraft, boats, property, garages, businesses and furniture.
- Mechanic requests only owned/unlocked vehicles.
- Story/Online-aware Contacts and Heist lists.
- Heist Room installation in an owned property, planning selection and getaway-vehicle selection.
- Large heists can require completed setups, an installed Heist Room and a compatible vehicle actually owned by the player. Missing vehicle returns `Vehicle Required`.
- Map marker state supports NEW/pulse, acknowledge-on-map and visited state, plus Story/Online marker separation fields.

This is systems groundwork; final rendered phone UI, interiors, animations and network synchronization remain later milestones.
