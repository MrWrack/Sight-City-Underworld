# Sight City: Underworld — Milestone 33

## Story Core + Mission 1
- Official game title switched to **Sight City: Underworld**.
- Online development remains frozen until Story is tested successfully on real PS Vita hardware.
- Added `StoryGameplay`, a Story-only runtime coordinator for mission progression and core systems.
- Implemented Mission 1 **Back in Sight City** as a playable objective/checkpoint sequence.
- Mission flow: meet Rhys -> enter his car -> Downtown -> West Suburbs -> East Coast -> North Countryside -> Mount Ridge -> return at night -> finish tour.
- Mission completion awards **$5,000 + 500 XP** and unlocks Mission 2 **Like Old Times**.
- English HUD/objective/notification strings are included.
- Existing world, traffic, emergency, weather, day/night, aircraft, fire/explosion, player and collision systems remain in the project.

This milestone is still a gameplay prototype. VitaSDK/hardware testing is required before claiming the Vita build runs correctly.
