# Milestone 23 — Terrain & Nature

Story-first world environment pass for Sight City.

- Deterministic streamed terrain height sampling.
- Mountains/hills, rocks/cliffs, trees and grass patches.
- Ocean/sea-level sampling, beaches and four offshore island zones.
- Large trees, rocks, cliffs and island terrain expose collision flags.
- Distance LOD tiers reduce vegetation detail for PS Vita.
- Uses the existing 64 m streaming-cell architecture and keeps the locked 120 x 120 km mainland coordinate layout.
- Online remains postponed until Story is playable/testable.

This is systems/procedural geometry data, not final art assets or final Vita rendering.
