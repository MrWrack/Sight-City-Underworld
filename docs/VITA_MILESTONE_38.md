# Milestone 38 — Trophy System

Story-only trophy foundation for Sight City: Underworld.

- Bronze / Silver / Gold / Platinum grades.
- Persistent save/load state.
- `Complete It All` is the only Platinum trophy.
- Platinum cannot be directly unlocked; it is awarded automatically only when every non-Platinum trophy is unlocked.
- Trophy definitions cover Story progression, Central Reserve, final Story completion, races, bicycle events, exploration, property/business ownership, vehicles, Wanted escape and aircraft.
- Intended PS Vita presentation: small trophy notification overlay plus a Trophy menu showing grade, name, description and completion percentage.
- Online code remains frozen pending physical PS Vita Story testing.
