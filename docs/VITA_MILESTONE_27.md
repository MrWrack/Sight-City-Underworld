# Milestone 27 - Dash 3D Player Controller

- Dash on-foot locomotion: idle, walk, run, sprint, stealth.
- Jump, gravity, falling and landing state.
- Animation-state interface via `PlayerMoveState`.
- Proximity-based enter vehicle and safe side exit.
- Player transform follows the controlled vehicle while driving.
- Existing Camera supports third-near, third-far and first-person follow.
- Vita controls remain: left stick movement, right stick camera, X sprint, Square jump, Circle stealth, Triangle enter/exit.
- Story Mode remains the development priority; Online is postponed.
